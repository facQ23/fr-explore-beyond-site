Privacy Policy

Last updated: October 16, 2026.

FR Explore Beyond AI is a personal project used by its operator to access authorized YouTube analytics and deliver reports to a designated Telegram chat.

Data accessed

The application requests read-only access to YouTube channel information and YouTube Analytics metrics such as views, watch time, and subscriber statistics.

How information is used

Data is used to prepare channel performance reports and may be sent to the operator's configured Telegram chat. The current deployment uses GitHub Actions to run scheduled reporting. The application does not sell YouTube user data.

Storage and third parties

Google OAuth authorization credentials and Telegram bot credentials are configured for the application and, for scheduled reporting, stored as GitHub Actions secrets. Reports are transmitted using Telegram's service. GitHub and Telegram process information under their own policies. Access to Google data may be logged by Google as part of API service operations.

Control and revocation

The operator can revoke access via Google Account third-party access, delete configured GitHub secrets, or disable the workflow. Google refresh authorization can expire or be revoked independently.

Contact

Use the application support contact shown on the Google consent screen to request information or deletion.
